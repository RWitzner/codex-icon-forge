# Monoline Suite app icon family

Eight coherent iOS launcher icons for a modern monoline app family.

## Variants (8)

- `calendar`: grid of date squares with one date circled and a small dot underneath, slight asymmetry top-right; accent only the circled date
- `mail`: rectangular envelope shown front-on, diagonal flap crease line, single small dot at the seal; accent only the seal dot
- `notes`: single paper page with three horizontal text lines and a folded top-right corner, pencil tip touching the bottom edge; accent only the pencil tip
- `maps`: teardrop location pin centered on a short curved path arc, tiny destination star at the arc's far end; accent only the destination star
- `music`: single eighth-note connected by a short stem to a three-peak waveform line; accent only the note dot
- `camera`: circular camera aperture iris with internal blade segments, small viewfinder square, and a shutter dot at top; accent only the shutter dot
- `wallet`: stacked card silhouette (two cards offset), embedded chip rectangle on the front card, small contactless arc; accent only the chip rectangle
- `search`: magnifying glass with a clean circular lens, short handle at lower-right, single tiny mark inside the lens; accent only the search mark

## Sizes

Each variant is provided at: 16x16, 32x32, 64x64, 128x128, 180x180, 256x256, 512x512, 1024x1024.

## Recommended use

- iOS / iPadOS App Store: use the 1024x1024 file in App Store Connect.
- macOS .icns generators: feed in the 16, 32, 64, 128, 256, 512, 1024 sizes.
- Android Play Store: use the 512x512 file.
- Web favicon: use 32x32 for the standard favicon, 180x180 for apple-touch-icon.
- Slack / Discord workspace icon: use the 512x512 file.

All files are PNG with transparent backgrounds. 64 files total.
