# Dev Pack sticker pack

Dev-themed Slack stickers for shipping, testing, deploying, and debugging.

## Stickers (12)

- `:shipping-it:` → `shipping-it.png` (joyful 'we shipped it' celebration)
- `:tests-passing:` → `tests-passing.png` (all-green test suite, calm confident vibe)
- `:merge-conflict:` → `merge-conflict.png` (tangled conflict knot, flustered but recoverable)
- `:ci-failed:` → `ci-failed.png` (red broken pipeline, frustrated face)
- `:deploy:` → `deploy.png` (rocket lifting off, confident motion)
- `:hotfix:` → `hotfix.png` (bandage on a server, urgent but stable)
- `:retry:` → `retry.png` (circular arrow, second-attempt energy)
- `:lgtm:` → `lgtm.png` (thumbs-up, looks good to me)
- `:wip:` → `wip.png` (work-in-progress sign, hard hat)
- `:debug:` → `debug.png` (magnifying glass on bug, focused)
- `:refactor:` → `refactor.png` (tidied gears or clean broom, satisfied)
- `:ship:` → `ship.png` (cargo ship sailing, steady and committed)

## Importing into Slack

1. Open your Slack workspace and click the workspace name -> Tools & settings -> Customize workspace -> Add Custom Emoji.
2. For each sticker, click *Add Custom Emoji*, upload the PNG, and use the suggested `:name:` shortcut.

You can drag every PNG in this folder into the Slack import dialog one at a time. Slack does not support bulk emoji import via UI.
